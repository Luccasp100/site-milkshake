# 🥤 Milkshake Mania - Personalizador de Pedidos

Uma aplicação web interativa e responsiva desenvolvida para proporcionar uma experiência imersiva na personalização e montagem de milkshakes. O projeto conta com fluxo de seleção de opções, adicionais acumulativos, animações em tempo real e cálculo instantâneo do pedido.

---

## 🚀 Sobre o Projeto

O **Milkshake Mania** foi criado para transformar a compra de uma sobremesa em uma jornada divertida e intuitiva. O usuário navega por etapas interativas onde escolhe o tamanho, sabor base, seleciona adicionais (com suporte a repetição do mesmo item) e finaliza visualizando o resumo do seu pedido com o valor total calculado automaticamente.

---

## 🛠️ Tecnologias Utilizadas

**React.js**, **GSAP**, **motion**, **CSS3**, **HTML5**, **JSON**, **JavaScript**

---

## ✨ Destaques do Site

- ⏳ **Tela de Loading Imersiva (GSAP):** Animação na tela de carregamento e mensagens dinâmicas enquanto a aplicação carrega.
- 🔴 **Indicador Visual de Unidades:** Badges animados nos cards mostrando a quantidade de cada adicional selecionado.
- ✨ **Transição Suave entre Telas (Fade In/Out):** Sistema customizado de transição de estado para evitar trocas bruscas de tela.
- 📱 **Totalmente Responsivo:** Layout fluido e adaptado para múltiplos dispositivos Desktops, Tablets e Smartphones.
- 🍓 **Adicionais com Repetição e Inventário:** Sistema flexível que permite selecionar até 3 adicionais no total, podendo **repetir o mesmo item**.
- 💰 **Cálculo em Tempo Real:** Atualização automática do valor do pedido a cada alteração feita pelo usuário.
